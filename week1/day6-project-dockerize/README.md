# Week 1 - Day 6: 미니 프로젝트 1 (1/2) - 앱 Dockerize

## 목표
- 본인의 간단한 앱을 컨테이너화한다

## 요구사항
- [ ] 직접 만들었거나 익숙한 웹 앱 1개 (언어 자유)
- [ ] 앱 + DB(PostgreSQL 또는 MySQL 또는 Redis) 구성
- [ ] 앱은 Dockerfile로 빌드 (가능하면 멀티스테이지)
- [ ] 설정값은 환경변수로 주입 (DB 주소, 비밀번호 등)
- [ ] DB 데이터는 볼륨으로 영속화

## 진행 순서
1. 앱을 로컬에서 먼저 실행해 정상 동작 확인
2. `.dockerignore` 작성
3. `Dockerfile` 작성, 단독 빌드/실행 확인
4. `docker-compose.yml`로 앱 + DB 연결
5. 컨테이너 재생성 후에도 데이터가 유지되는지 확인

## 체크리스트
- [ ] `docker compose up -d` 한 번으로 전체 기동
- [ ] 비밀번호가 Dockerfile에 하드코딩되어 있지 않다
- [ ] 이미지 크기를 확인하고 줄일 여지를 점검했다
- [ ] 컨테이너가 root가 아닌 사용자로 실행된다 (`USER`)
